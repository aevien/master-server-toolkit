# FishNet Bridge

This bridge contains FishNet-based demo integration for MST rooms, lobbies and worlds.

## Scope

- Room/client/master/spawner demo scenes and prefabs.
- FishNet room network managers and access-validation messages.
- Demo character movement/profile/vitals scripts.
- Basic world/zone demo assets.

## Rules

- Do not move FishNet-specific types into MST core modules.
- Treat included character/gameplay scripts as examples.
- Keep room access validation aligned with MST `Rooms` contracts.
- Preserve demo scene assumptions unless updating the matching examples and documentation.
